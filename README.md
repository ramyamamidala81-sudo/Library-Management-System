# Library Management System

A Java-based Library Management System using JDBC and MySQL.

## Features
- Add Books
- View Books
- Borrow Books
- Return Books
- Database Storage

## Technologies Used
- Java
- JDBC
- MySQL
- VS Code
- Git & GitHub

## How to Run
1. Clone repository
2. Setup MySQL database
3. Configure JDBC connection
4. Run Main.java
